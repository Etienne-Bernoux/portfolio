Règles de confidentialité

Application « Home Assistant Nyons ». Dernière mise à jour : 21 octobre 2026.

Qui utilise l'application

Une seule personne : Etienne Bernoux, son auteur. L'application n'est proposée à personne d'autre.

Données Google utilisées

L'application demande l'accès drive.file : elle ne voit que les fichiers qu'elle crée elle-même dans Google Drive. Elle y dépose les sauvegardes de Home Assistant et les relit pour les restaurer. Elle n'accède à aucun autre fichier du Drive, ni aux autres données du compte Google.

Partage et conservation

Aucune donnée n'est transmise à un tiers, vendue ni utilisée à d'autres fins. Les sauvegardes restent dans le Google Drive de l'utilisateur, qui peut les supprimer à tout moment. L'accès se retire depuis la page « Applications tierces » du compte Google.

Privacy policy

Application "Home Assistant Nyons". Last updated: 21 October 2026.

Who uses the application

A single person: Etienne Bernoux, its author. The application is not offered to anyone else.

Google data used

The application requests the drive.file scope: it can only see the files it creates itself in Google Drive. It stores Home Assistant backups there and reads them back to restore them. It does not access any other file in the Drive, nor any other Google account data.

Sharing and retention

No data is shared with third parties, sold or used for any other purpose. Backups stay in the user's Google Drive, where the user can delete them at any time. Access can be revoked from the "Third-party apps" page of the Google account.
